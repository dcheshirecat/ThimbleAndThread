# Thimble & Thread
You inherit your great-aunt's haberdashery in a seaside town. It opens at dusk. Customers are each stitching a story.
Chapters: 1 Cross stitch / 2 Knitting / 3 Embroidery / 4 Crochet (rival shop opens) / 5 Sewing (Community Quilt, endings by relationships).
Mystery: great-aunt's pattern book with missing pages - max a relationship to earn a page.
Screen flow: Title > Save select > Shop hub > Dialogue > Order > Workbench > Minigame > Result > Deliver > Shop. Side screens: Supply market, Pattern Studio, Journal, Settings. Then End-of-day summary.
